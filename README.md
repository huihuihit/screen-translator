# 화면 번역기 (안드로이드)

폰 화면에 보이는 영어, 일본어, 중국어를 한국어로 번역해서 원래 글자 위에 겹쳐 보여주는 앱이에요.
글자 인식은 늘 폰 안에서 하고, 번역은 아래 순서로 해요. 온라인 번역에는 **인식된 글자만** 보내고 화면 이미지는 보내지 않아요.

1. **Gemini** (기본, 무료 사용량): 한 화면의 글을 한꺼번에 보내서 앞뒤 문맥을 살려 번역해요.
2. **Google Cloud Translation**: Gemini 무료 한도를 다 썼거나, 번역을 거부했거나, 오류가 나면 이걸로 번역해요.
   앱이 이번 달 보낸 글자 수를 세다가 무료분(월 50만 자)에 닿으면 더 보내지 않아요. 그래서 요금이 나가지 않아요.
3. **기기 안 번역** (ML Kit): 인터넷이 안 되거나 위 두 개가 모두 실패하면 폰 안에서 번역해요.

API 키를 하나도 넣지 않으면 예전처럼 기기 안 번역만 써요. 번역 결과 아래쪽에 어떤 엔진으로 번역했는지 표시돼요.

## 어떻게 동작하나요

1. 앱에서 "번역 시작"을 누르면 화면 위에 동그란 **번역** 버튼이 떠요.
2. 번역하고 싶은 앱(웹툰, 게임, 웹페이지 등)을 열고 번역 버튼을 누르면
3. 지금 화면을 찍어서 글자를 찾고(구글 ML Kit 글자 인식, 폰 안에서), 위 순서대로 한국어로 번역한 뒤
4. 원래 글자가 있던 자리에 번역문을 덮어서 보여줘요. 화면을 아무 데나 누르면 닫혀요.

버튼은 끌어서 옮길 수 있고, 길게 누르거나 알림의 "중지"를 누르면 끝나요.

## APK 파일 받는 방법

프로젝트 채팅에서 Claude가 만들어 준 `screen-translator.apk` 를 폰으로 받으면 돼요.
코드를 고친 뒤 새로 만들고 싶으면 채팅에 "화면 번역 앱 APK 빌드해줘" 라고 보내 주세요.

### 방법 2: 폰에서 바로 받는 고정 링크 만들기 (GitHub)

이 폴더에는 GitHub에 올리기만 하면 APK를 자동으로 만들어 주는 설정(`.github/workflows/build-apk.yml`)이 들어 있어요.

1. https://github.com/signup 에서 GitHub 계정을 만들어요 (무료).
2. https://github.com/new 에서 새 저장소를 만들어요. 이름은 예를 들어 `screen-translator`,
   공개 여부는 Private 로 해도 되고, 아무 파일도 추가하지 않은 빈 저장소로 만들어요.
3. https://claude.ai/connect-github 에서 Claude에 GitHub 계정을 연결해요.
4. https://github.com/apps/claude/installations/select_target 에서 Claude 앱을 방금 만든 저장소에 설치해요.
5. 이 프로젝트의 **프로젝트 설정 → 리소스(resources)** 에서 그 저장소를 추가하고,
   채팅에 "screen-translator 저장소에 코드 올려줘" 라고 보내 주세요.
6. 코드가 올라가면 GitHub이 몇 분 안에 APK를 만들어요. 폰 브라우저로
   `https://github.com/<내 아이디>/screen-translator/releases/tag/latest` 에 들어가서
   `screen-translator.apk` 를 받으면 돼요. (Private 저장소면 폰 브라우저에서 GitHub에 로그인해야 해요.)

## 폰에 설치하고 처음 쓰는 방법

1. **APK 설치**: 받은 `screen-translator.apk` 파일을 폰에서 열어요.
   "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용** 을 켜고 설치를 계속해요.
   (Play 프로텍트 경고가 뜨면 "무시하고 설치"를 누르세요. 직접 만든 앱이라 뜨는 경고예요.)
2. **앱 열기**: 앱 목록에서 **화면 번역기** 를 열어요.
3. **원문 언어 고르기**: 보통은 "자동 감지"로 두면 돼요. 한 언어만 번역한다면 그 언어를 고르는 게 더 정확해요.
4. **1단계, 다른 앱 위에 표시 권한**: "권한 설정 열기"를 누르고, 목록에서 화면 번역기를 찾아 허용으로 바꾼 뒤 뒤로 가기.
5. **2단계, 번역 모델 받기**: 와이파이에 연결한 상태에서 "번역 모델 다운로드"를 누르세요.
   영어, 일본어, 중국어, 한국어 모델 합쳐 약 90MB이고, 세 언어 모두 ✓ 가 되면 끝이에요. 이건 처음 한 번만 하면 돼요.
6. **3단계, 번역 시작**: "번역 시작"을 누르면
   - 알림 권한을 물어보면 **허용** (알림에서 바로 중지할 수 있어요),
   - 화면 녹화/공유 확인 창이 뜨면 **시작** 을 눌러요. 안드로이드 14 이상에서 "앱 하나 공유 / 전체 화면 공유"를 고르라고 하면
     **전체 화면 공유** 를 골라야 다른 앱에서도 번역돼요.
7. 번역할 앱을 열고 떠 있는 **번역** 버튼을 누르면 끝!

온라인 번역을 쓰려면 아래 "온라인 번역 키 받기"대로 키를 받아서, 앱의 **온라인 번역 (선택)** 칸에 붙여 넣고
**온라인 번역 설정 저장** 을 누르세요. 2단계 기기 안 번역 모델도 받아 두면 인터넷이 없을 때도 번역돼요.

화면 공유 허락은 번역을 시작할 때마다 한 번씩 물어봐요. 안드로이드 보안 정책이라 건너뛸 수 없어요.

## 온라인 번역 키 받기

키 두 개는 앱 안에만 저장되고, 번역할 때 구글 서버로만 보내요. 남에게 보여 주지 마세요.

### Gemini API 키 (무료, 카드 등록 필요 없음)

1. 폰이나 PC 브라우저로 https://aistudio.google.com/apikey 에 들어가서 구글 계정으로 로그인해요.
2. 처음이면 이용 약관에 동의해요.
3. **API 키 만들기(Create API key)** 를 눌러요. 프로젝트를 고르라고 하면 기본 프로젝트를 고르거나 새로 만들어요.
4. 만들어진 키(`AIza…` 로 시작)를 **복사** 해요.
5. 앱의 **Gemini API 키** 칸에 붙여 넣어요. **Gemini 모델** 칸은 비워 두면 `gemini-3.8-flash` 를 써요.

알아둘 점: 무료 사용량은 분당·하루 요청 수에 한도가 있어요(AI Studio의 사용량 화면에서 확인).
한도를 넘으면 앱이 알아서 Cloud Translation으로 넘어가요. 또 무료 사용량으로 보낸 글은 구글이
서비스 개선에 쓸 수 있어요. 개인 정보가 많은 화면에서는 번역하지 않는 게 좋아요.

### Google Cloud Translation API 키 (매달 50만 자까지 무료, 카드 등록 필요)

1. https://console.cloud.google.com 에 같은 구글 계정으로 로그인해요.
2. 위쪽 프로젝트 선택 메뉴에서 프로젝트를 골라요. Gemini 키를 만든 프로젝트를 그대로 써도 되고 새로 만들어도 돼요.
3. 왼쪽 메뉴 **결제(Billing)** 에서 결제 계정을 연결해요. 카드 등록이 필요하지만, 매달 50만 자까지는 요금이 나오지 않아요.
   걱정되면 **예산 및 알림** 에서 1달러 같은 작은 금액으로 알림을 걸어 두세요.
4. https://console.cloud.google.com/apis/library/translate.googleapis.com 에 들어가서 **사용(Enable)** 을 눌러요.
5. **API 및 서비스 → 사용자 인증 정보** 로 가서 **사용자 인증 정보 만들기 → API 키** 를 눌러요.
6. 만들어진 키의 **키 수정** 에서 **API 제한사항 → 키 제한** 을 고르고 **Cloud Translation API** 만 체크한 뒤 저장해요.
   (키가 새어 나가도 번역에만 쓰이게 하는 안전장치예요.)
7. 키를 복사해서 앱의 **Cloud Translation API 키** 칸에 붙여 넣어요.

앱은 이 폰에서 보낸 글자 수만 세요(설정 화면에 이번 달 사용량이 보여요). 같은 키를 다른 곳에서도 쓰면 앱이 모르니,
그럴 땐 위 3번의 예산 알림을 꼭 걸어 두세요.

## 알아두면 좋은 점

- 은행 앱, 넷플릭스처럼 화면 캡처를 막아 둔 앱은 까만 화면으로 찍혀서 번역이 안 돼요.
- 기기 안 번역은 구글 번역 웹보다 품질이 떨어져요. 인터넷 없이 폰 안에서 도는 작은 모델이라서 그래요.
- Gemini 무료 사용량은 바뀔 수 있어요. 새 Flash 모델이 나오면 **Gemini 모델** 칸에 그 이름을 넣으면 돼요.
- 세로쓰기 일본어나 손글씨, 아주 작은 글자는 잘 못 읽을 수 있어요.
- 번역 대기 중에는 화면을 계속 캡처하고 있어서 배터리를 조금 더 써요. 다 쓰면 버튼을 길게 눌러 꺼 주세요.

## 개발자용 정보

- 언어/빌드: Kotlin, Gradle 8.9, Android Gradle Plugin 8.5.2, minSdk 26 (안드로이드 8.0), targetSdk 34
- 빌드 명령: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
- 서명: 저장소의 `debug.keystore`(비밀번호 `android`)로 서명해서, 어디서 빌드해도 기존 앱 위에 업데이트 설치가 돼요.
- 주요 파일
  - `MainActivity.kt`: 설정 화면 (권한, 모델 다운로드, 온라인 번역 키, 시작/중지)
  - `ScreenCaptureService.kt`: 화면 캡처(MediaProjection) 유지, 떠 있는 버튼, 결과 창
  - `TranslationEngine.kt`: ML Kit 글자 인식(라틴/일본어/중국어), 자동 언어 추정, 번역 엔진 순서(Gemini → Cloud → 기기 안)
  - `OnlineTranslator.kt`: Gemini `generateContent`(한 화면을 JSON 배열로 묶어 보냄)와 Cloud Translation v2 호출
  - `Prefs.kt`: 원문 언어, API 키, Gemini 모델 이름 저장 (앱 전용 저장소, 백업 제외)
  - `TranslationOverlayView.kt`: 번역문을 원래 글자 위치에 그리는 화면
